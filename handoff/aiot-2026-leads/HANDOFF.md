# 인수인계: AIoT 국제전시회 2026 참가기업 콜드메일 리드 수집

## 1. 목표
AIoT 국제전시회 2026 **공식 참가기업 전체**를 수집해 B2B 콜드메일 발송용 리드 리스트(CSV)로 만든다.

## 2. 전시회 정보
| 항목 | 내용 |
|---|---|
| 행사명 | AIoT 국제전시회 2026 (AIoT Korea Exhibition 2026) |
| 일정 | 2026-11-03(화) ~ 11-05(목), 10:00~17:00 |
| 장소 | 코엑스 3층 D홀 |
| 주최 / 주관 | 과학기술정보통신부 / (사)한국지능형사물인터넷협회(한국AI사물인터넷협회), 케이훼어스(주) |
| 사무국 | aiot@kiot.or.kr / 02-3454-1260 |
| 규모(2025 참고) | 150~160개사, 약 350부스 |
| 공식 참가기업 페이지 | https://www.aiotkorea.or.kr/2026/kor/about/exhibitor.asp |

## 3. 지금까지 한 일 (이전 세션)
- 이전 세션은 **클라우드 환경이라 aiotkorea.or.kr 접속이 네트워크 정책으로 차단(403)** 됨. WebFetch도 DNS 실패.
- 그래서 뉴스 보도자료(2026-09-23 네이트 뉴스 등) 기반으로 **16개사**만 확보 → `seed-16.csv`
  - 2026 참가 확정 13개사: 아모에스넷, 멀티택시스템즈, 아이오티랩, 이모션웨이브, 트리니오, 이투온, 씨앤테크, 비전파크, 에이아이텔레콤, 이노랩스, 드란비, 아바드, 엠피웨이브
  - 2025 참가(2026 재참가 미확인) 3개사: SK텔레콤, 영신, 지엔
- 이메일/홈페이지는 미확인 상태(지어내지 않음).

## 4. 남은 작업 (이번 세션)
1. **로컬 PC 인터넷으로** 공식 참가기업 페이지 접속 (curl / PowerShell / Node fetch 중 되는 것).
2. 1페이지 HTML을 먼저 받아 구조 파악: 목록 항목 셀렉터, 페이지네이션 파라미터명, 상세페이지 링크 패턴.
3. 전체 페이지 + 기업별 상세 페이지 순회. 요청 간격 ≥ 1초, robots.txt 확인.
4. 수집 항목: 기업명, 부스번호, 전시품목, 회사소개, 홈페이지, 대표 이메일, 대표 전화.
5. `seed-16.csv`와 병합·중복 제거 → 결과 저장.
6. 사이트가 로컬에서도 막히면: 원본 HTML을 `output/aiot-2026-leads/raw/`에 저장하고 사용자에게 보고. 대체로 웹검색 보도자료 추가 수집.

## 5. 출력 규격
- 파일: `output/aiot-2026-leads/aiot-2026-exhibitor-leads-full.csv` (UTF-8 **BOM**, 엑셀 호환)
- 컬럼:
  `구분, 기업명, 부스번호, 출품 제품, 분야, 이 회사의 타깃 고객, 콜드메일 훅(영업 포인트), 우선순위, 홈페이지, 대표 이메일, 대표 전화, 출처 URL, 담당자/이메일(직접 확인), 발송일, 회신`
- 우선순위:
  - **A** 중소·중견 + 파트너/유통/PoC/레퍼런스 확보 니즈가 보임
  - **B** 일반 중소기업
  - **C** 대기업·공공기관 (콜드메일 효율 낮음)
- 콜드메일 훅: 회사소개/전시품목에서 **구체적인 한 줄** 인용 (예: "샘플 공급·PoC 파트너 확보가 목표").

## 6. 규칙
- **개인 담당자 이메일 추측·생성 금지.** 사이트에 공개된 회사 대표 연락처만.
- 확인 못 한 값은 빈칸. 지어내지 말 것.
- `output/`은 gitignore 대상 → 결과 CSV는 커밋되지 않음(회사 데이터 보호 목적, 정상).
- 정보통신망법: 광고성 메일은 제목에 (광고) 표기, 수신거부 방법 명시 필요 — 템플릿 작성 시 반영.

## 7. 완료 보고 형식

- A등급 상위 10개사 표
- 콜드메일 템플릿 1종 (개인화 변수 포함)
