# 인스타그램 수주 플레이북

> 목표는 팔로워가 아니라 **문의(DM) → 견적 → 수주**입니다.
> 모든 게시물은 "이 계정에 맡기면 되겠다"는 판단을 한 단계씩 앞당기기 위해 존재합니다.
> `/insta-new`, `/insta-calendar`, `/insta-dm`이 이 파일을 기준으로 동작합니다. (회사 데이터 없음 — 공개 레포에 포함)

---

## 1. 의뢰자가 계정을 보고 판단하는 순서

```
게시물 1개 발견 → 프로필 방문 → 고정 게시물 3개 → 하이라이트 → 피드 스크롤 → DM
```

이 동선에서 하나라도 막히면 문의가 오지 않습니다. 그래서 **게시물보다 프로필이 먼저**입니다 (`/insta-setup`).

| 단계 | 의뢰자의 질문 | 답하는 곳 |
|------|---------------|-----------|
| 발견 | "이거 나한테 필요한 얘기인가?" | 게시물 1장째 (훅) |
| 프로필 | "뭐 하는 곳이지? 나 같은 사람도 받나?" | 이름 필드 + 소개 4줄 |
| 고정 게시물 | "실력이 진짜인가?" | 대표 사례 · 진행 과정 · 후기 |
| 하이라이트 | "얼마고, 얼마나 걸리고, 어떻게 맡기지?" | 포트폴리오 · 후기 · 진행 과정 · 비용/FAQ · 문의 방법 |
| DM | "답장 빨리 오나? 귀찮게 안 하나?" | DM 자동응답 + 첫 응답 시간 |

---

## 2. 프로필 공식

**이름 필드 (검색 노출)**: `브랜드명 | 핵심 서비스 2개` — 예: `브랜드 | 상세페이지·브랜딩 디자인`

**소개 4줄 공식**
1. 무엇을 — 서비스를 의뢰자 언어로 (전문용어 X)
2. 누구를 — 받는 고객 범위 (업종·규모)
3. 증거 — `brand-facts.md`의 실수치 1개 (없으면 대표 레퍼런스)
4. 행동 — `DM "<키워드>"` 또는 `👇 견적 문의`

**고정 게시물 3개**: ① 대표 사례 (Before/After) ② 진행 과정 + 비용 구조 ③ 후기 모음

**하이라이트 5개 (순서 고정)**: 포트폴리오 → 후기 → 진행 과정 → 비용/FAQ → 문의 방법

---

## 3. 게시물 7유형

| 유형 | `type` | 퍼널 | 역할 | 필수 조건 |
|------|--------|------|------|-----------|
| 작업 사례 | `portfolio` | 신뢰 | "실력 증명" — 문제 → 한 것 → 결과 | **실제 작업물 이미지 1장 이상** |
| 의뢰자 교육 | `tip` | 발견 | 저장·공유로 도달 확장 — "이렇게 하면 망합니다" | 고객의 실수 1개에 집중 |
| 진행 과정 | `process` | 신뢰 | "맡기면 어떻게 되나" 불안 제거 | 실제 단계·기간 (profile.md) |
| 비용 가이드 | `price` | 전환 | 진지한 문의만 오게 필터링 | 가격 공개 범위 준수 |
| 후기 | `review` | 신뢰 | 사회적 증거 | 동의 받은 원문만 |
| FAQ | `faq` | 전환 | 망설임(가격·기간·수정·소통) 해소 | profile.md의 반론 목록 |
| 작업 가능 일정 | `offer` | 전환 | 결정 촉진 | **실제 남은 슬롯만** (가짜 희소성 금지) |

**4주 기본 믹스 (주 3회 = 12개)**: portfolio 4 · tip 3 · process 2 · review 1 · price 또는 faq 1 · offer 1

같은 유형을 연속 2회 이상 올리지 않습니다.

## 4. 캐러셀 구조 (4:5, 1080×1350)

```
1장  훅        — 의뢰자의 문제/손실을 30자 이내로. 결과물 이미지가 있으면 1장에 크게.
2장  공감/문제  — "이런 상황이시죠?"
3~N장 본문     — 한 장에 메시지 하나. 제목 30자, 본문 90자 이내.
N+1장 증거     — 실제 작업물 / 결과 수치 (portfolio.md, brand-facts.md에 있는 것만)
마지막 CTA     — DM 키워드 하나. "DM으로 '견적' 보내주시면 ○시간 안에 답드립니다"
```

- 슬라이드 5~10장 권장 (최대 20)
- **작업 사례·후기 슬라이드는 실제 이미지(`source: "real"`)**, 텍스트 카드만 AI 생성(`source: "ai"`)
- AI로 가짜 작업물·가짜 목업·가짜 후기 캡처를 만들지 않습니다 — 디자인 회사에게는 치명적인 신뢰 손실

---

## 5. 캡션 공식

```
[첫 줄 훅 — 45자 이내, 피드에서 '더 보기' 전에 보이는 부분]

[문제 2~3줄]
[우리가 한 것 / 핵심 내용 3~5줄]
[증거 1줄 — 확인된 수치·사례]

👉 [CTA — DM 키워드 + 응답 시간]

#해시태그 3~5개
```

- 캡션 300~1,500자 권장 (최대 2,200자)
- 해시태그 **최대 5개** (인스타그램 정책 변경 반영) — 브랜드 1 + 서비스 2 + 의뢰자 업종 2
- 캡션 안 URL은 클릭되지 않음 → "프로필 링크"로 안내
- 수치는 `brand-facts.md` / `portfolio.md`에 있는 것만 (픽션 금지)

---

## 6. DM → 수주 동선

1. **키워드 자동응답** (비즈니스 계정 → 자동화된 응답 / 저장된 답장) — DM 키워드에 즉시 반응
2. **첫 응답**: 감사 + 견적에 필요한 정보 3~4개만 질문 (profile.md `견적에 꼭 필요한 정보`)
3. **견적 발송**: 범위·기간·포함/불포함을 짧게, 비교 가능한 옵션 2개
4. **후속 연락**: 견적 후 24시간 / 3일 — 압박하지 않고 질문 하나로
5. **수주 후**: 작업이 끝나면 `portfolio.md`에 사례 추가 → 다음 portfolio 게시물로 순환

`/insta-dm`이 이 단계별 답장 초안을 만듭니다.

---

## 7. 주간 점검 지표

| 지표 | 의미 | 낮으면 고칠 곳 |
|------|------|----------------|
| 게시물 도달 | 발견 | 1장째 훅, tip 비중 |
| 프로필 방문 | 관심 | 캡션 CTA, 게시물 → 프로필 유도 |
| 링크 클릭 / DM 문의 | 의도 | 소개 4줄, 하이라이트, 고정 게시물 |
| 견적 발송 → 수주 | 전환 | DM 응답 속도, 견적 구성 |

팔로워 수는 지표에 넣지 않습니다.

---

## 하지 않는 일

- 팔로우/좋아요 자동화, 맞팔 이벤트 (계정 제재 + 의뢰자와 무관한 팔로워)
- 자동 게시 (사람이 검수 후 앱에서 직접 업로드)
- 가짜 후기, 가짜 마감 임박, 확인 안 된 수치
