받은 메시지: "$ARGUMENTS"

DM은 수주가 실제로 결정되는 곳입니다. 빠르고, 짧고, 다음 행동이 분명해야 합니다.

## 사전 로드
1. `knowledge/instagram/profile.md` — 서비스·가격 공개 범위·응답 시간·견적 필요 정보
2. `knowledge/instagram/portfolio.md` — 문의 업종과 비슷한 사례
3. `knowledge/brand-facts.md` — 수치 (여기 없는 숫자 금지)
4. `knowledge/instagram/playbook.md` 6장 — DM → 수주 동선

## 단계 판단 (`--stage` 없으면 메시지로 추정)
- **first** (첫 문의): 감사 1줄 → 비슷한 사례 1개 언급 → 견적 필요 정보 3~4개 질문 → 응답 시간 약속
- **quote** (정보 받음): 범위·기간·포함/불포함 요약, 옵션 2개, 다음 단계 1개 (통화/계약서)
- **followup** (답 없음): 24시간 / 3일 버전 각 1개 — 질문 하나로, 압박·할인 남발 금지
- **댓글**: 공개 답글은 짧게 + "DM 드렸어요" / "DM으로 '<키워드>' 보내주세요"

## 출력
- 답장 초안 2안 (짧은 버전 / 친절한 버전), 각 300자 이내
- 확인 필요: 초안에 들어간 가격·기간이 profile.md와 맞는지
- 받은 메시지에 가격 협상·무리한 일정·무료 시안 요구가 있으면 대응 포인트 1줄

## 하지 않는 일
- 직접 DM 발송 (사람이 앱에서 보냄)
- profile.md에 없는 가격·할인·일정 약속
