"$ARGUMENTS" 게시물의 업로드 어시스턴트를 엽니다.

1. 폴더 경로 추정:
   - `2026-10-03_상세페이지리뉴얼` 같은 폴더명만 줬다면 `output/instagram/$ARGUMENTS`
   - 전체 경로면 그대로 사용

2. 실행:
   ```bash
   node scripts/insta-preview.js --folder "output/instagram/..."
   ```

3. 브라우저에서:
   - 슬라이드를 업로드 순서대로 확인, 비어 있는 실물 슬라이드 표시

   - 캡션 전체 / 본문만 / 해시태그만 복사
   - 업로드 체크리스트 10개
